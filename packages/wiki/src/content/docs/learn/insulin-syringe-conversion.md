## Insulin Syringe Conversion Chart

Insulin syringes measure doses in "units" rather than milliliters. For peptide researchers using insulin syringes for subcutaneous injection, converting between units and mL is essential for accurate dosing.

## Syringe Types

| Syringe Type | Concentration | Units per mL | Common Use |
|--------------|---------------|-------------|------------|
| U-100 | 100 units/mL | 100 | Standard insulin, peptide injection |
| U-500 | 500 units/mL | 500 | High-concentration insulin |
| U-40 | 40 units/mL | 40 | Veterinary insulin |

**Most peptide researchers use U-100 syringes.** This chart assumes U-100 unless specified.


## Practical Dosing Examples

### Example 1: BPC-157 at 250 µg

**Reconstitution:** 5 mg vial + 5 mL BAC water = 1 mg/mL

**Calculation:**

```
Volume = 0.25 mg ÷ 1 mg/mL = 0.25 mL = 25 units
```

### Example 2: Semaglutide at 0.25 mg

**Reconstitution:** 3 mg vial + 1 mL BAC water = 3 mg/mL

**Calculation:**

```
Volume = 0.25 mg ÷ 3 mg/mL = 0.083 mL ≈ 8.3 units
```

### Example 3: CJC-1295 at 100 µg

**Reconstitution:** 2 mg vial + 4 mL BAC water = 0.5 mg/mL

**Calculation:**

```
Volume = 0.1 mg ÷ 0.5 mg/mL = 0.2 mL = 20 units
```

### Example 4: Ipamorelin at 200 µg

**Reconstitution:** 5 mg vial + 5 mL BAC water = 1 mg/mL

**Calculation:**

```
Volume = 0.2 mg ÷ 1 mg/mL = 0.2 mL = 20 units
```

## Syringe Specifications

### Common Syringe Sizes

| Syringe Volume | Graduation | Increment | Best For |
|----------------|------------|-----------|----------|
| 0.3 mL | 0.01 mL | 1 unit | Low-dose peptides |
| 0.5 mL | 0.01 mL | 1 unit | Most peptide doses |
| 1.0 mL | 0.01 mL | 1 unit | Higher volumes |

## Common Errors

| Error | Consequence | Prevention |
|-------|-------------|------------|
| Using U-500 as U-100 | 5× overdose | Check syringe label |
| Misreading graduation | Incorrect dose | Read at plunger seal |
| Drawing air bubbles | Underdose | Tap syringe, expel air |
| Using wrong syringe | Inaccurate measurement | Match syringe to volume |
| Not accounting for dead space | Slight underdose | Use low dead-space syringes |

## Safety Considerations

- **Always verify** syringe type (U-100 vs U-500)
- **Use appropriate needle** for injection route
- **Rotate injection sites** to prevent lipodystrophy
- **Dispose of needles** in FDA-cleared sharps container
- **Never share** syringes or needles
